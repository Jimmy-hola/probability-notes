① 學習目標 Goals

讀完本節,你應該能不假思索地回答:

  • 條件機率 $P(A \mid B)$ 的定義是什麼?為什麼分母要除以 $P(B)$?
  • 為什麼要求 $P(B) > 0$?
  • 怎麼用 multiplication rule 把 $P(A \cap B)$ 拆成兩個易算的量?
  • $P(A \mid B)$ 與 $P(B \mid A)$ 是同一回事嗎?差在哪裡?
  • 條件機率在 Pebble World 裡的幾何意義是什麼?

前置檢查(快速 self-check)

Q0-1. 等機率有限樣本空間 $\Omega$ 下,事件 $E$ 的機率怎麼算?
展開答案
$P(E) = |E| / |\Omega|$ — 第 1.3 節 naive definition。本節會「在縮限樣本空間到 B」之後再套這個直覺。
Q0-2. 對任何兩個事件 $A, B$,$A \cap B$ 與 $A \cup B$ 哪一個一定比較「小」(機率較低)?
展開答案
$P(A \cap B) \le \min(P(A), P(B)) \le P(A \cup B)$。intuition:「同時發生」比「擇一發生」更嚴格。
這個直覺很重要 — 條件機率的分子永遠是 $P(A \cap B)$。
Q0-3. 想像你丟一顆公正六面骰。事件 $A=\{$點數為 3$\}$、$B=\{$點數為奇數$\}$。$P(A)=?$、$P(B)=?$、$P(A \cap B)=?$
展開答案
$P(A)=1/6$、$P(B)=3/6=1/2$、$A \cap B = A$,所以 $P(A \cap B) = 1/6$。記住這三個數字 — 等下會用。

② 蘇格拉底鏈 Build the definition

下面 6 題會帶你從一個具體例子,一步步「逼出」條件機率的定義。每題請先試著自己想 1–2 分鐘,再展開提示或解答。

1 縮限樣本空間
丟兩顆公正的骰子(顏色不同,可分辨先後)。已知兩顆點數和等於 7,問「第一顆是 3」的機率是多少?
💡 提示
列出所有「和為 7」的結果(順序對 = (第一顆, 第二顆))。在這些結果中,有多少個第一顆是 3?
✅ 解答 + 為什麼
和為 7 的 outcomes 有 6 個:$(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)$,共 6 個。 其中「第一顆 = 3」只有 $(3,4)$ 一個,所以條件機率 $= 1/6$。
注意:這恰好等於「無條件下第一顆 = 3」的機率 $1/6$ — 純屬巧合。下一題我們換條件就會看到差別。
2 換個條件,結果就不同
改成已知兩顆點數和為 4,問「第一顆是 3」的機率是多少?跟 Q1 對照,為什麼有時「知道 B」改變了 A 的機率、有時不改?
💡 提示
和為 4 只有 3 個 outcomes。在這 3 個之中第一顆是 3 的有幾個?算出比例後,再回頭問自己:「條件改變機率的本質是什麼?」
✅ 解答 + 為什麼
和為 4:$(1,3),(2,2),(3,1)$,共 3 個。其中第一顆 = 3 的只有 $(3,1)$。所以 $P = 1/3$,跟無條件的 $1/6$ 不一樣。

本質:條件 $B$ 把樣本空間從 36 個 outcomes 縮限到 $|B|$ 個,然後在這個小空間裡重新看 $A$ 佔多少比例。 有時這個比例剛好等於原本的 $P(A)$(Q1),有時不等於(Q2) — 是否相等,後續會用「獨立性」這個概念精確刻畫(§2.4)。

3 從直覺寫出定義
把 Q1、Q2 的算法一般化:在縮限樣本空間到 $B$ 之後,$A$ 在新空間中所佔的「機率比例」是什麼?
試著寫出 $P(A \mid B)$ 的定義式,並回答:為什麼分子是 $P(A \cap B)$ 而不是 $P(A)$?
💡 提示
在縮限後的 $B$ 中,$A$ 中那些「不在 B 裡」的 outcomes 還有可能發生嗎?
✅ 解答 + 為什麼
Definition 2.1.1 (Blitzstein & Hwang): $$P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}, \quad \text{provided } P(B) > 0.$$

為什麼分子是 $P(A \cap B)$:一旦你「知道 B 發生了」,$\Omega$ 裡所有不在 B 的 pebbles 全部被剔除。 在剩下的 pebbles 中,讓 $A$ 也成立的,只剩 $A \cap B$ 這一塊。 所以條件下「A 占多少比例」就是 $\frac{P(A \cap B)}{P(B)}$ — 分母是新樣本空間的總質量,用來把比例「重新正規化」回 $[0,1]$。

兩個操作要記牢:(1) 縮限 sample space 到 B;(2) 重新正規化 除以 $P(B)$。 這個雙步驟結構在後面的 Bayes、conditional independence、條件期望都會反覆出現。

4 為什麼要求 $P(B) > 0$?
定義中明確寫了 $P(B) > 0$。如果 $P(B) = 0$,$P(A \mid B)$ 為什麼不能直接定義?有什麼直覺與技術理由?
💡 提示
先看數學上會發生什麼:$0/0$ 是?再看直覺:「在不可能發生的事的條件下」這句話有意義嗎?
✅ 解答 + 為什麼
技術上:分母為 0,$P(A \cap B)/P(B)$ 沒有定義(且 $A \cap B \subseteq B$ 必有 $P(A \cap B)=0$,得 $0/0$)。 直覺上:條件機率回答的是「假設 B 真的發生了,A 的機率是多少」 — 若 B 是不可能事件,這個假設本身就矛盾。

不過進階機率(measure theory)中,常常需要對 $P(B)=0$ 的事件條件化(例如連續隨機變數 $X=x$ 的條件分布,因為單點機率為 0)。 那時要用 regular conditional probability / Radon–Nikodym 導出的版本來處理。本書 §9 之後會碰到雛形。

5 反推 Multiplication Rule
從定義 $P(A \mid B) = P(A \cap B)/P(B)$ 兩邊乘 $P(B)$,你得到什麼?
這個重寫版本在實務建模時為什麼比定義本身更有用?嘗試講出兩個原因。
💡 提示
想像你在描述一個「按時間順序」展開的隨機過程:先發生某事 B,後續才有 A。那麼模型自然會給你 $P(B)$ 與 $P(A \mid B)$,而不是 $P(A \cap B)$。
✅ 解答 + 為什麼

Multiplication rule (Theorem 2.1.2): $$P(A \cap B) = P(B) \cdot P(A \mid B) = P(A) \cdot P(B \mid A).$$

為什麼比定義更有用:

  1. 順著建模方向走:很多隨機過程是「逐步揭露」的(先抽第一張牌,再抽第二張;先生病,再做檢測)。 模型自然提供 $P(\text{第一步})$ 與 $P(\text{第二步} \mid \text{第一步})$;multiplication rule 直接給 joint。
  2. 可以鏈式推廣:對 $n$ 個事件, $$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \, P(A_2 \mid A_1) \, P(A_3 \mid A_1 \cap A_2) \cdots P(A_n \mid A_1 \cap \cdots \cap A_{n-1}).$$ 這就是 chain rule,Bayes nets / 機率圖模型的基礎。

定義是「分析工具」(把 conditional 拆成 joint/marginal),multiplication rule 是「綜合工具」(把 marginal/conditional 組成 joint)。學會雙向流暢轉換,後面條件機率的計算就會像呼吸一樣自然。

6 $P(A \mid B)$ vs $P(B \mid A)$ — 並從中看見 Bayes
用「有病 vs 檢測陽性」的場景,說明 $P(A \mid B)$ 與 $P(B \mid A)$ 為何不能互換。
更進一步:把這兩個式子串起來(都用 multiplication rule 表達 $P(A \cap B)$),你會得到什麼公式?
💡 提示
$P(A \mid B) \cdot P(B) = P(A \cap B) = P(B \mid A) \cdot P(A)$。把中間的 $P(A \cap B)$ 去掉,解出 $P(A \mid B)$。
✅ 解答 + 為什麼

令 $A = \{\text{有病}\}$、$B = \{\text{檢測陽性}\}$。

  • $P(B \mid A)$ = 「有病的人檢測呈陽性」的機率 = 敏感度(sensitivity),通常很高,例如 0.99。
  • $P(A \mid B)$ = 「檢測陽性的人實際有病」的機率 = 陽性預測值(PPV),在罕見病的場景可能只有 0.10 甚至更低。

兩者差很多!混淆它們就是著名的 base rate fallacy / prosecutor's fallacy。

把 multiplication rule 雙向寫: $$P(A \mid B) \, P(B) = P(A \cap B) = P(B \mid A) \, P(A).$$ 解出 $P(A \mid B)$: $$\boxed{\, P(A \mid B) = \dfrac{P(B \mid A) \, P(A)}{P(B)} \,}$$ 這就是 Bayes' rule 的最原始形式 — 我們已經把它偷偷從 2.1 的定義裡推出來了!§2.2 會把 $P(B)$ 用 law of total probability 進一步展開,完成完整版本。

關鍵 takeaway:條件機率不對稱。「給定 B 看 A」和「給定 A 看 B」是兩件事,中間靠 prior $P(A)$ 與 marginal $P(B)$ 換算。 這個「翻轉條件方向」的能力,就是貝氏推論的核心。

④ 關鍵原則 & 常見誤區 Lock it in

本節最重要的 3 件事

  1. 條件機率 = 縮限 + 重新正規化。$P(A \mid B) = P(A \cap B)/P(B)$ 不是天上掉下來的公式 — 它就是「把 $\Omega$ 縮成 $B$,再算 $A$ 在新空間中的比例」。
  2. Multiplication rule 是建模利器。$P(A \cap B) = P(B) P(A \mid B) = P(A) P(B \mid A)$,可以鏈式展開到任意多個事件(chain rule)。
  3. 條件機率本身仍是一個合法的 probability measure。固定 $B$ 後,$Q(\cdot) := P(\cdot \mid B)$ 滿足機率公理(non-negative、$Q(\Omega)=1$、$\sigma$-additivity)。這個事實 §2.3 會明寫,但現在心裡就要有這個影子 — 它讓我們在「條件下的世界」可以照常做所有機率運算。

常見誤區

  • 方向混淆:把 $P(A \mid B)$ 當成 $P(B \mid A)$。 舉例:「99% 的恐怖份子在機場安檢會被攔下,所以被攔下的人 99% 是恐怖份子」 — 錯,忽略了 prior(恐怖份子在旅客中極稀有)。
  • 把條件當對稱:誤以為 $P(A \mid B) + P(A \mid B^c) = 1$。事實上是 $P(A \mid B) + P(A^c \mid B) = 1$(條件下仍是 measure)。
  • 忘掉 $P(B) > 0$:條件在 $P(B) = 0$ 的事件上,需要更進階的工具(regular conditional probability),不要硬套定義式。
  • 把「縮限」做了但忘了「正規化」:例如算出 $|A \cap B|/|\Omega|$ 然後當成 $P(A \mid B)$ — 那只是 $P(A \cap B)$。要記得分母從 $|\Omega|$ 換成 $|B|$。

⑤ 自我檢驗題 Try it

建議先紙筆推導,再展開對照。

A 撲克牌
從一副標準 52 張撲克牌中隨機不放回抽兩張。已知第一張是 ace,問第二張也是 ace 的機率? 請(1)直接用條件機率定義算;(2)再用 multiplication rule 反推 $P(\text{兩張都是 ace})$。
✅ 解答
(1) 第一張是 ace 之後,牌堆剩 51 張、其中還有 3 張 ace。 $$P(A_2 \mid A_1) = \dfrac{3}{51} = \dfrac{1}{17}.$$ (2) 由 multiplication rule: $$P(A_1 \cap A_2) = P(A_1) \cdot P(A_2 \mid A_1) = \dfrac{4}{52} \cdot \dfrac{3}{51} = \dfrac{12}{2652} = \dfrac{1}{221}.$$

反思:如果問「兩張都是 ace」我們是不是也能用 naive 數法 $\binom{4}{2}/\binom{52}{2}$?算算看會發現結果一樣 — 為什麼?(因為等機率有限空間下兩種方法等價。)

B Story proof:條件下的補事件
證明 $P(A^c \mid B) = 1 - P(A \mid B)$。請用兩種方法:(i) 直接從定義,(ii) 用「條件機率本身也是 probability measure」這個觀點。
✅ 解答

(i) 直接從定義: $$P(A^c \mid B) = \dfrac{P(A^c \cap B)}{P(B)} = \dfrac{P(B) - P(A \cap B)}{P(B)} = 1 - \dfrac{P(A \cap B)}{P(B)} = 1 - P(A \mid B).$$ 中間用到 $A^c \cap B = B \setminus (A \cap B)$ 且 $A \cap B \subseteq B$。

(ii) Measure 觀點:令 $Q(\cdot) = P(\cdot \mid B)$。$Q$ 是合法 probability measure(§2.3 會證),所以對任何事件 $A$,$Q(A^c) = 1 - Q(A)$,即 $P(A^c \mid B) = 1 - P(A \mid B)$。

為什麼這個 story proof 重要:它告訴你 — 一旦你建立了「條件下的世界」,所有原來在無條件機率裡學到的恆等式(de Morgan、inclusion-exclusion、Boole's inequality、…)全部都能照搬,只要把 $P$ 換成 $P(\cdot \mid B)$ 即可。這是巨大的 leverage。

C Monty Hall(條件機率版)
三扇門,只有一扇後面有車,你的目標是選中車。流程:你先選 door 1;主持人(他知道車在哪)從剩下兩扇門中開一扇有山羊的;若兩扇都有山羊,他等機率挑一扇開。已知主持人開了 door 3(且後面確實是山羊),問「換到 door 2 會贏」的條件機率?
💡 提示
令 $C_i$ = 車在 door $i$,$H_3$ = 主持人開了 door 3。先寫 $P(C_i)$(都是 1/3),再寫 $P(H_3 \mid C_i)$ 對 $i=1,2,3$(注意 $C_3$ 時主持人不可能開 door 3)。最後用 Bayes 算 $P(C_2 \mid H_3)$。
✅ 解答

$P(C_1) = P(C_2) = P(C_3) = 1/3$。給定車的位置,主持人開 door 3 的條件機率:

  • $P(H_3 \mid C_1) = 1/2$(主持人可開 door 2 或 3,等機率)
  • $P(H_3 \mid C_2) = 1$(主持人不能開有車的 door 2,也不能開你選的 door 1,只能開 door 3)
  • $P(H_3 \mid C_3) = 0$(他絕不開有車的門)

用 multiplication rule 算 $P(H_3)$: $$P(H_3) = \tfrac{1}{2}\cdot\tfrac{1}{3} + 1\cdot\tfrac{1}{3} + 0\cdot\tfrac{1}{3} = \tfrac{1}{2}.$$ Bayes: $$P(C_2 \mid H_3) = \dfrac{P(H_3 \mid C_2) P(C_2)}{P(H_3)} = \dfrac{1 \cdot 1/3}{1/2} = \dfrac{2}{3}.$$ 所以換門勝率 = 2/3;不換(車在 door 1)勝率 = 1/3。

為什麼很多人直覺得是 1/2:他們把「兩扇門剩下」當成「等可能」,忽略了主持人開 door 3 這個動作本身攜帶了關於車的位置的資訊。 條件機率的核心 — 不只看「結果」,還要看「為什麼這個結果會被觀察到」。
